Choose import options and replace missing fonts before importing. Press Options, then choose a file, to switch auto layout, HTML layer names, style and variable creation, existing local styles and hyperlinks on or off; the choices are remembered per site. When a capture uses fonts you do not have, pick a replacement for each, with the nearest match already chosen. The report now counts auto layout frames, frames without it, and styles and variables created and reused, and states plainly any that could not be created.
