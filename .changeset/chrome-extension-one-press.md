One Capture button and eight fixed sizes in the popup: TV, Desktop, Laptop, Tablet landscape, Tablet portrait, Phone landscape, Phone portrait and Watch. Each has its own width (120 to 3840, editable) and a tick, and the button saves every ticked size in one `.frottage` file. The plain "Capture this page" path is gone.
