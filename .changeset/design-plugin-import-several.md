Import several files at once: choose or drop up to 8 `.frottage` files (600 MB in all). Files of one page are ordered widest first, then themes and languages, and import one after another with progress per file. The review step shows once, with the missing fonts of every file. A file that fails is named in the report and the others carry on, and the report lists each version.
