Choose widths in the popup: "Capture at several widths" resizes the window to each ticked width (1512, 1440 and 834 by default, each editable from 320 to 3840) and saves one file per width, with a Cancel button. Widths under 500 can't be reached by resizing, so the popup explains how to capture them in Chrome's DevTools device mode, and a plain capture at that width is labelled with it.
