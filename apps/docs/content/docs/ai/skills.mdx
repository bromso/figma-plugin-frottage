## What are skills?

Skills are instructions that teach Claude how to perform specific tasks. This repository ships none, so the skills available to Claude are the ones in your own setup.

## Adding skills

Third-party skills are not vendored into the repository. If you want one, install it into your own Claude Code setup, for example from [skills.sh](https://skills.sh) or the [Anthropic skills repository](https://github.com/anthropics/skills), and it will be available when you work here. The superpowers plugin's `writing-skills` skill is a good way to create your own.
