## What are skills?

Skills are instructions that teach Claude how to perform specific tasks. This template ships one skill, written for this repository, so Claude already knows how to build a Figma plugin with it.

## Installed skill

### build-figma-plugin

Describe your plugin idea in plain English and Claude generates everything:
- Plugin code (Figma API interactions)
- UI code (React components from `@repo/ui`, styled to Figma's UI3 look)
- Message types (communication between plugin and UI)
- Build validation (build, type-check, lint and tests)
- Installation guide (how to load it into Figma)

It lives in `.claude/skills/build-figma-plugin/` with reference documents on the architecture, the UI components and the Figma API patterns the template uses.

## Adding skills

Third-party skills are not vendored into the repository. If you want one, install it into your own Claude Code setup, for example from [skills.sh](https://skills.sh) or the [Anthropic skills repository](https://github.com/anthropics/skills), and it will be available alongside the template's skill. The superpowers plugin's `writing-skills` skill is a good way to create your own.
